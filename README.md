## 🛠️ Local Development

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/Varad-Khopkar/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build & Validation
```bash
# Run linter
npm run lint

# Compile TypeScript & build for production
npm run build

# Preview production build locally
npm run preview
```
